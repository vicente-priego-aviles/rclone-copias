# rclone-copias

Página principal y política de privacidad de una aplicación personal de Google Cloud que usa [rclone](https://rclone.org/) para copias de seguridad cifradas en Google Drive.

Google exige estas dos páginas para pasar la aplicación a «producción» (si no, el acceso caduca cada 7 días). No hay nada más: ni código ni datos.

- Página principal: https://vicente-priego-aviles.github.io/rclone-copias/
- Privacidad: https://vicente-priego-aviles.github.io/rclone-copias/privacidad.html
